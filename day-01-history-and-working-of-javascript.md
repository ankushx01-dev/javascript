# What is JavaScript?

JavaScript is a programming language used to make web pages interactive and dynamic.

It helps in:
- Adding functionality to websites
- Handling user interactions
- Creating dynamic content
- Building web applications

# How JavaScript Works

JavaScript runs inside the browser using a **JavaScript Engine**.

The engine:
1. Reads the code
2. Interprets the code
3. Executes the code
4. Shows output

---

# Popular JavaScript Engines

| Browser | Engine |
|------|------|
| Chrome | V8 |
| Firefox | SpiderMonkey |
| Safari | JavaScriptCore |

---

# Interpreted Language

JavaScript is mainly an interpreted language.

This means:
- Code runs line by line
- No separate compilation needed before execution
- Faster testing and development

Modern JavaScript engines also use **JIT (Just-In-Time) Compilation** to improve performance.

---

# What is REPL?

REPL stands for:

| Letter | Meaning |
|------|------|
| R | Read |
| E | Evaluate |
| P | Print |
| L | Loop |

---

# How REPL Works

```text
Read    -> Takes input
Evaluate -> Executes code
Print   -> Shows output
Loop    -> Repeats process
```

---

# REPL Example

```javascript
> 2 + 3
5

> console.log("Hello")
Hello
```

REPL helps developers test JavaScript code quickly.
